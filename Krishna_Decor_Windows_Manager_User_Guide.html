01 Overview & Desktop Shell Architecture

The Krishna Decor Windows Desktop Manager App serves as the central administrative hub for business owners and project managers. Built as a high-performance native desktop application with an integrated local background hub, it manages design projects, on-site measurements, fabric estimations, client quotations, and commercial tax invoicing.

Core Architectural Capabilities:
  • Single Instance Lock: Prevents multiple application windows from conflicting. Launching the desktop shortcut while already running instantly restores and focuses your active session.
  • Background Tray Running: Closing the main application window minimizes it to the Windows notification tray (near the clock) rather than shutting down, keeping background synchronizations active.
  • Local Disk Mirroring: All project data, staff submissions, and billing records automatically mirror to your local hard drive (%AppData%\krishna-decor-manager-desktop\data\krishna-decor.json) in real time. Full read and write capabilities are preserved even during internet outages.

02 Getting Started & Sign-In

Launch Krishna Decor Manager from your Desktop shortcut or Windows Start Menu. The system will load the login gateway.

  1. Enter your registered Manager user name or email (e.g., Dinesh) and secure password.
  2. Click Sign in. Your authenticated session is encrypted and retained securely.
  3. The app automatically verifies connectivity with the cloud database (Render cloud API) and your local backup mirror.

Top Navigation Status Indicators:

  • Synced — All project edits, quotes, and customer records are safely backed up to both cloud and local storage.
  • Syncing — Background transactions are actively transmitting.
  • Offline Mode — Work continues uninterrupted; all actions are queued locally and automatically committed once connectivity is restored.

03 Project & Customer Profile Management

Projects represent individual customer sites (villas, apartments, commercial offices). Every project encapsulates its measured spaces, material line items, staff drafts, formal quotations, and payment milestones.

Creating a Project:

  1. Click the + New Project button in the left sidebar.
  2. Enter the Project / Site Name (e.g., Gomtesh Nagar Villa 4).
  3. Fill in customer details: Customer Full Name, Primary Mobile Number, and Site Address.
  4. Optionally designate an Assigned Staff Member (e.g., isra) so the job immediately routes to that technician's mobile measurement device.
  5. Click Create Project.

Use the fast search bar (Ctrl + F) at any time to instantly filter your client list by name, address, phone number, or project status.

04 Rooms, Spaces & Multi-Measurement Openings

Rooms represent individual dressing areas within a project. The manager app supports standard residential and commercial spaces as well as custom named zones.

Multi-Measurement Openings per Room:

A single room often contains multiple windows, French doors, or balconies requiring different fabric cuts. Rather than creating duplicate rooms, the manager app allows defining multiple measurement sets within a single area:

  • Select the room (e.g., Living Room) and click + Add Measurement Set.
  • Provide a descriptive label (e.g., Main Balcony Window, Dining Side Window).
  • Enter Width and Height in your preferred unit: Inches (in), Feet (ft), Meters (m), or Centimeters (cm).
  • The app standardizes measurements internally into inches and automatically updates the room's cumulative Measured Coverage (Total Sq Ft).

05 Materials Catalog & Automated Cost Formulas

When adding materials to any room, Krishna Decor's proprietary calculation engine (calculateProduct) automates fabric yardage, pleating allowances, drop calculations, and billable square footage:

1. Eylet & Ripple Curtains Formula (Main Curtains, Sheers, Linings)
Panels (A) = ⌈Width / 20⌉
Drops (B) = (Height + 15) / 39
Total Fabric Quantity = A × B (meters, strictly rounded to 2 decimal places)
Width is divided by 20 inches and rounded up to determine the required fabric panels (A). 15 inches is added to the height for top heading and bottom hem allowances, then divided by 39 inches per meter to determine drops (B).
2. American Pleat Curtains Formula
Panels = ⌈Width / 18⌉
Drops = (Height + 15) / 39
Total Fabric Quantity = Panels × Drops (meters)
Divides width by 18 inches to accommodate standard American pleat fullness.
3. Valence / Valance Curtains Formula
Breadths = ⌈Width / 50⌉
Quantity = ⌈((Breadths × 15) / 39) × 2⌉ / 2 (rounded to nearest 0.5 meter)
Calculates required pattern breadths based on 50" fabric width, rounding to the nearest half-meter.
4. Roman Blinds Formula
Fabric Quantity = ⌈Width / 50⌉ × ((Height + 20) / 39) (meters)
Chargeable Area = ⌈(Width / 12) × 2⌉ / 2 × ⌈(Height / 12) × 2⌉ / 2 (sq ft, min. 11 sq ft)
Includes stitching surcharge (Standard: ₹200/sq ft, Premium: ₹350/sq ft) and enforces an 11 sq ft minimum billable threshold per blind.
5. Surface Coverings (Roller / Zebra / Venetian Blinds, Wallpaper, Carpet)
Area = (Width / 12) × (Height / 12) (sq ft)
6. 16 Manual Quantity Materials with Optional Measurements

Bed border fabric, Bed back making, Soft board fabric, Soft board making, Seating fabric, Seating making, Pillow fabric, Pillow, Mattress, Wallpaper rolls, Wallpaper pasting, Customised wallpaper, Customised wallpaper pasting, Carpet, Bed sheet, Bed set.

These designated materials allow direct entry of piece counts (pcs) or rolls while keeping dimensional entries optional.

06 Automatic Curtain Hardware Calculations

Hardware is never estimated by guesswork. Whenever curtains are added to any room, the system runs curtainHardwareLines to automatically calculate all necessary tracks, accessories, and brackets:

Hardware Component Calculation Formula Unit GST Rate
Track (Running Length) ⌈Width in inches / 12⌉ for each curtain set Running ft 18%
Runners Track Running Feet × 3 (3 runners per running foot) Pieces (pcs) 18%
Hooks Track Running Feet × 3 (3 hooks per running foot) Pieces (pcs) 18%
Mounting Clamps max(2, ⌈Track Running Feet / 3⌉ + 1) based on chosen clamp type Pieces (pcs) 18%
Clamp Options Supported: Ceiling Clamps, Single wall clamp, or Double wall clamp. The quantity scales dynamically with the track span.

07 Field Staff Coordination & Draft Ingestion

Field technicians capture physical measurements on-site using the mobile app and upload them directly to your workspace.

  • Field Review Alert: When staff submit measurements, an alert appears in the room workspace detailing the staff member's name and specific notes.
  • Edit & Approval: Managers can modify dimensions, change clamp types, or override prices before accepting the draft into the official project scope.
  • Tombstone Deletion Protection: If a manager deletes an erroneous or test submission from the staff feed, the system logs a permanent local deletion tombstone. This guarantees that subsequent cloud sync operations will not restore the deleted item.

08 Quotations: Generation, Editing & Math Derivation

Quotations transform raw room specifications into formal commercial estimates presented to clients.

1. Creating a Quotation

In the project view, navigate to the Quotations tab and click Create Quotation. The system generates an official quotation record with an automated sequence identifier (e.g., KD-26-001).

2. Inline Sheet Editing

You can fine-tune values directly on the rendered quotation sheet:

  • Quantity: Editable inline, strictly formatted to 2 decimal places.
  • Unit Price: Editable inline in Indian Rupees (₹). Totals and taxes update in real time.

3. Mathematical Formula Transparency

To build complete trust with clients, every line item displays its mathematical derivation directly beneath the product name:

Formula: ⌈144"/20⌉ × (108"+15)/39 = 8 panels × 3.15 drops = 25.23 m

Clients immediately see how their window dimensions translate into fabric meterage, eliminating confusion or disputes.

4. Unified Hardware Section at Bottom

Rather than cluttering the quotation with hardware line items under every separate bedroom and window, the manager app automatically consolidates (unifyQuoteItems) all hardware into unified items at the bottom of the document:

  1. Track (consolidated running feet across all rooms)
  2. Runners (total consolidated count)
  3. Hooks (total consolidated count)
  4. Mounting Clamps (grouped by clamp type)

5. Comparing & Approving Drafts

  • Compare Drafts: Click Compare Drafts to inspect a side-by-side comparison of untaxed amounts, GST taxes, and final totals across different revisions.
  • Approval: Once accepted, set the status dropdown from Draft to Approved. This locks the pricing and enables the Tax Invoice and Payment modules.

09 Tax Invoicing, Commercial Billing & PDF Export

Once a quotation is marked Approved, the app unlocks the official Tax Invoice view.

Commercial Invoicing Differences:

  • Sanitized Product Descriptions: Unlike quotations, commercial invoices omit internal formula descriptions, room prefixes, and dimensional math notes, presenting a clean line item description (e.g., Ripple main curtain).
  • Dual-Table Structure:
    1. Primary Table: Main decorative fabrics, curtain sets, blinds, wallpapers, and bespoke items.
    2. Secondary Table: Track hardware, runners, hooks, clamps, stitching labor, installation, and delivery charges.
  • Statutory Tax Breakdown:
    • 5% GST: Applied to core textile fabrics, curtain cloths, and upholstery.
    • 18% GST: Applied to stitching services, blinds, hardware, installation, and transport.
    • Summarized into Untaxed Amount, SGST / UTGST, CGST, and Grand Total.
  • Standard Terms & Bank Details: Includes company GSTIN (29AWZPK1722G1Z4), payment terms (70% advance, 30% prior to delivery), Axis Bank wire transfer details, and customer signature line.
  • Printing & PDF: Click Print Bill or Save PDF (or press Ctrl + P) to open the native Windows print dialog. Select Save as PDF to export a client-ready document.

10 Payment Logging & Overpayment Prevention

Keep financial records synchronized throughout the project lifecycle:

  • Open the Payments panel on any approved project.
  • Click Record Payment, specify the amount received, payment mode (NEFT/RTGS, UPI, Cheque, Cash), and reference number.
  • Server-Side Guardrail: The backend API strictly validates that cumulative payments cannot exceed the approved quotation total, blocking accidental overpayments with a 400 Bad Request safety response.
  • The document footer automatically calculates and displays the current Balance Due.

11 Windows Desktop Hub: Sync & Local Backups

The Windows desktop application includes a dedicated management utility: Windows Hub Sync Settings. Access it via the top application menu (Krishna Decor → Windows Hub Sync Settings) or by right-clicking the system tray icon.

Hub Feature Description & Operating Procedure
Test Cloud Connection Sends a ping to the cloud server and reports connection health and round-trip latency in milliseconds.
Sync Now Triggers an immediate two-way synchronization between your local Windows PC and the 24/7 cloud server.
Open Local Data Folder Opens Windows File Explorer directly to your local database folder containing krishna-decor.json and daily archives.
Export Backup Prompts a Windows Save File dialog to export a complete .json database snapshot to an external drive or secondary backup folder.
Import Backup Restores an existing backup file. A safety copy of your current database is automatically created prior to restoring.
Start at Windows Login Ensures Krishna Decor launches automatically in the notification tray when your Windows computer starts up.
